# Equity Research Portfolio

Independent investment research, industry notes, and reflections informed by experience in accounting, audit, and financial planning and analysis.

**Author:** Xavier Chen · MS Finance, Fordham University  
**Format:** Written research and presentation materials, rather than a software application.

## Project description

This repository collects my work on companies, industries, and investment frameworks. My focus is connecting financial statements and business economics with valuation, risk, and the questions that deserve further research.

The materials are dated research snapshots. Their presence here does not imply that a view is current, that every document has been independently verified, or that third-party reference material was authored by me.

## Tech stack and formats

The repository currently contains PDF presentations/reports, Word documents, and Markdown navigation. No application, package installation, or automated valuation pipeline is included.

## Installation

No installation is required to read the Markdown or preview supported files on GitHub. To keep a local copy:

```bash
git clone https://github.com/Xiaowen-CHEN-Learner/Equity-research.git
cd Equity-research
```

Use a PDF reader or a compatible document editor for the relevant files.

## Usage

Read each document in its historical context and check its as-of date before applying its conclusions. When reviewing an investment argument, distinguish source observations, modelling assumptions, valuation estimates, and the author's interpretation.

For reuse or citation, identify the specific document, its author or contributors, and its date. Do not treat this collection as a live recommendation service.
